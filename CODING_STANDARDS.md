# Coding standards

## Documentation

- Write package READMEs for package users: installation, public usage and configuration.
- Keep ADRs focused on the decision, rationale and consequences.
- Describe user-facing changes in release notes. Mark a new package's first release as its initial release.
- Describe current behavior. Include migration instructions when users need to change their code or configuration.
- Include implementation details only when they help the reader complete a task.
