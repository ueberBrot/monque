Available entries describe shipped features. Planned entries describe future work
without a release date.

See [Dashboard setup](/monque/dashboard/express/) for the available integration.
Job priorities are available across core, Management, and Dashboard. See
[priority changes](/monque/core-concepts/management/#change-priority) for pending Jobs.
